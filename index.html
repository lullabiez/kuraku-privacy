Kebijakan Privasi — KuraKu

Terakhir diperbarui: 1 Agustus 2026

KuraKu (paket aplikasi: com.kuraku.exoticpet) adalah aplikasi jurnal perawatan hewan eksotik yang bekerja sepenuhnya offline. Kebijakan privasi ini menjelaskan bagaimana aplikasi memperlakukan data Anda.

1. Pengumpulan Data

KuraKu tidak mengumpulkan, mengirim, atau membagikan data pribadi apa pun ke server atau pihak ketiga. Aplikasi tidak memerlukan akun, registrasi, maupun koneksi internet untuk berfungsi.

2. Data yang Anda Simpan Sendiri

Seluruh data yang Anda masukkan (profil hewan, foto, catatan berat, makan, shedding, kawin, pengingat, dll.) disimpan hanya di dalam perangkat Anda menggunakan basis data lokal (SQLite/Room) dan penyimpanan internal aplikasi. Data ini tidak pernah keluar dari perangkat Anda.

3. Izin (Permissions)

  • Kamera — hanya untuk memindai kode QR profil hewan dan mengambil foto. Gambar tidak dikirim ke mana pun.
  • Akses foto/media — hanya untuk memilih foto dari galeri Anda ke profil hewan.
  • Notifikasi & Alarm — hanya untuk menampilkan pengingat perawatan yang Anda buat sendiri.

Tidak ada izin yang digunakan untuk melacak atau mengunggah data Anda.

4. Berbagi via QR Code

Fitur berbagi profil lewat QR Code bekerja sepenuhnya offline: data hanya dipindahkan antar perangkat secara langsung melalui gambar QR, tanpa melewati server mana pun.

5. Data Anak-anak

Aplikasi ini tidak ditujukan untuk mengumpulkan data dari siapa pun, termasuk anak-anak.

6. Penghapusan Data

Karena semua data tersimpan lokal, Anda dapat menghapusnya kapan saja dengan menghapus data di dalam aplikasi atau meng-uninstall aplikasi. Tidak ada salinan data di tempat lain.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan dipublikasikan pada halaman ini.

8. Kontak

Untuk pertanyaan mengenai kebijakan privasi ini, hubungi pengembang melalui: https://saweria.co/kurakurakoding.
